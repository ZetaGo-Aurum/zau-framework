Quick Start

Scaffold in Seconds

Get started with a single command via npm or pip. ZAU scaffolds a production-grade fullstack project equipped with async ORM, 3D spatial canvas, and hot reload.

Node / NPM Workflow 
npm create zau@latest my-app
cd my-app
zau dev --port 8000
Python / Pip Workflow 
pip install zau-framework
zau create my-app --template fullstack-3d
cd my-app
zau dev

CLI Commands Reference

zau dev --port 8000

Launch local development server with Python ASGI hot-reload and 3D HMR.

zau db studio

Opens the built-in database inspector to browse tables, records, and run SQL.

zau db migrate / upgrade

Inspect ORM model schema changes and automatically apply database migrations.

zau build / start

Compile frontend assets, type bridges, and run multi-worker production cluster.

Dual-Tier Unified Architecture

Eliminating the rift between backend Python APIs and client reactive interfaces.

01

FastAPI-Grade Python Core

ASGI uvloop micro-kernel running asynchronous Server Actions (@app.action) with type validation, automatic serialization, and bidirectional WebSockets.

02

Native 3D Spatial Canvas

First-class <ZAU.Canvas3D> primitive embedding WebGL/WebGPU render loops directly inside component lifecycles, ready for GLTF/GLB asset loading.

03

Dual Styling Engine

Zero-friction interoperability: atomic utility classes from Tailwind CSS combined with structural grid and component tokens from Bootstrap 5.3 without CSS collisions.
