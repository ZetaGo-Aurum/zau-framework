## 1. Executive Summary & Architecture Decisions

ZAU is an industrial-grade fullstack web framework designed to overcome the extreme fragmentation in modern web development (seen in ecosystems like React, Vue, Vite, and Next.js). ZAU is led by **ZetaGo-Aurum** with the goal of bringing end-to-end Pythonic simplicity, native spatial 3D WebGL rendering, integrated asynchronous ORM, and dual-asset styling interoperability (Tailwind CSS + Bootstrap) without convoluted configuration.

### 1.1 Architecture Selection Matrix

| Category / Feature | Chosen Standard | Status | Technical Rationale |
| :--- | :--- | :--- | :--- |
| **Core Server Language** | **Python (>=3.11)** | **APPROVED** | Concise syntax, FastAPI/Starlette async performance, Pydantic v2 type safety. |
| **Database Engine** | **Async ORM + Migrations** | **APPROVED** | Zero-config embedded SQLite for dev; 1-line switch to PostgreSQL/MySQL in prod. |
| **3D Spatial Canvas** | **Native `<ZAU.Canvas3D>`** | **APPROVED** | Declarative WebGL/Three.js primitives built directly into core lifecycle. |
| **Styling & Assets** | **Tailwind CSS + Bootstrap** | **APPROVED** | Zero-setup dual engine: atomic utility classes paired with Bootstrap structural tokens. |

## 3. Core Modules Specification

### 3.1 Native Database Subsystem (Async ORM)
```python
from zau.db import Model, Field, Relationship
from typing import Optional, List
from datetime import datetime

class User(Model, table=True):
    id: Optional[int] = Field(default=None, primary_key=True)
    username: str = Field(index=True, unique=True, max_length=50)
    email: str = Field(unique=True, index=True)
    password_hash: str
    is_active: bool = Field(default=True)
    created_at: datetime = Field(default_factory=datetime.utcnow)
    projects: List["Project"] = Relationship(back_populates="owner")
```

### 3.3 Server Action RPC & Realtime Sync
```python
from zau import ZAUApp, Depends
from zau.db import get_session, AsyncSession, select

app = ZAUApp(title="ZAU Suite", client_dir="../frontend")

@app.action("/api/projects/list")
async def list_projects(limit: int = 10, session: AsyncSession = Depends(get_session)):
    statement = select(Project).limit(limit)
    result = await session.execute(statement)
    return [p.to_dict() for p in result.scalars().all()]
```
