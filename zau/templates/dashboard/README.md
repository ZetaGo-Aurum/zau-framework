# My ZAU Application

Built with **ZAU Framework (ZetaGo-Aurum Unified)**.
Python-first Fullstack Web Engine & Native 3D Spatial Canvas.

## Getting Started

```bash
# Start development server (Python ASGI + 3D Canvas + Live Reload)
zau dev --port 8000

# Open Database Studio Inspector
zau db studio

# Build for production
zau build

# Start production cluster
zau start --workers 4
```
