# ZAU Framework Language Support for VS Code

Official Visual Studio Code & Cursor extension for **ZAU Framework (`.zau`) Single File Components**.

## Features

- **Rich Syntax Highlighting**: Colorizes `<template>`, `<script>`, `<style>`, and `<ZAU.Canvas3D>` native spatial tags.
- **Directives Support**: Highlights event directives like `@click`, `:bind`, and reactive attributes.
- **Snippets**: Quick scaffolding for `.zau` components, 3D spatial scenes, and server actions.

## Installation

Install via the VS Code Marketplace or build manually with `vsce package`.
