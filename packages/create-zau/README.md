# create-zau

Official project scaffolding CLI for **ZAU Framework (ZetaGo-Aurum Unified)**.

## Quick Start

```bash
# Using npm
npm create zau@latest my-app

# Using npx
npx create-zau my-app

# Using pnpm
pnpm create zau my-app

# Using yarn
yarn create zau my-app
```

## Available Templates

- `fullstack-3d`: Python ASGI Core + Native Three.js 3D Spatial Canvas + Async ORM + Tailwind CSS & Bootstrap Dual Engine.
- `minimal`: Lightweight minimalist setup for rapid prototyping.
- `dashboard`: Full administrative system with database metrics and real-time cards.
- `portfolio`: Spatial showcase tailored for high-end personal atelier & 3D visualization.
