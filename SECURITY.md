# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within ZAU Framework, please send an email to **ZetaGo-Aurum Security Team** at `admin@zetagoaurum.com`.

Please include:
- A description of the vulnerability and its potential impact.
- Steps to reproduce or proof-of-concept code.
- Any suggested mitigations.

We will acknowledge receipt within 48 hours and work with you on a coordinated disclosure timeline.
