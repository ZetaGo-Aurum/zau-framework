# Changelog

All notable changes to ZAU Framework are documented in this file.

## [1.0.0] - 2026-09-07

### Added
- **Python ASGI Core**: High-throughput Starlette/uvloop micro-kernel with FastAPI-grade syntax.
- **Server Action Auto-RPC**: Decorator-driven backend RPC with automatic serialization and dependency injection.
- **Native Asynchronous ORM**: Unified SQLModel/SQLAlchemy 2.0 async engine supporting SQLite, PostgreSQL, and MySQL.
- **ZAU DB Studio**: Built-in web database inspector and SQL runner.
- **Native 3D Spatial Canvas**: First-class `<ZAU.Canvas3D>` primitive with WebGL/Three.js render loop.
- **Dual Asset Adapter**: Integrated Tailwind CSS atomic utilities and Bootstrap 5.3 structural tokens.
- **ZAU CLI Tooling**: Commands for `create`, `dev`, `build`, `start`, `db`, and `highlight`.
- **.zau Syntax Highlighter**: Custom token-level lexer and syntax interpreter rendering semantic HTML and ANSI.
- **VS Code Language Support**: TextMate grammar and snippets for `.zau` Single File Components.
- **create-zau**: Interactive npm/npx project scaffolding CLI.
- **Multi-Platform Deployment**: Native support for Vercel, Render, Replit, and Docker multi-stage builds.
