# Contributing to ZAU Framework

Thank you for your interest in contributing to **ZAU Framework**!

## Development Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/ZetaGo-Aurum/zau-framework.git
   cd zau-framework
   ```

2. Create and activate a Python virtual environment:
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   pip install -e .
   ```

3. Run the CLI tool:
   ```bash
   zau version
   zau --help
   ```

## Commit Guidelines

- Use clear, descriptive commit messages adhering to Conventional Commits:
  - `feat:` for new features
  - `fix:` for bug fixes
  - `docs:` for documentation updates
  - `perf:` for performance optimizations
  - `refactor:` for internal architectural improvements

## Code Standards

- Follow PEP 8 and use type hints across all Python modules.
- Ensure strict TypeScript compatibility in client runtime libraries.
- No AI slop or unnecessary filler code.
